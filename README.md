# Bullseye Inventory Management System

A Java backend service for managing inventory operations — products, orders, order items, employees, suppliers, and issue reports — built with **Spring Boot** and **MySQL**. It exposes a REST API designed to be consumed by an Angular frontend (CORS is pre-configured for `http://localhost:4200`).

## Features

- **Product management** — list, look up, add, update, and delete products (name, cost, quantity, weight, season, shelf location, image)
- **Order management** — place orders, update order status, and view all orders (with subtotal, shipping, tax, and grand total)
- **Order items** — attach line items to an order and retrieve items by order ID
- **Employee directory** — list employees and look one up by email
- **Supplier directory** — list suppliers and look one up by name
- **Issue reporting** — submit reports and retrieve reports by recipient

## Tech Stack

- **Language:** Java 17
- **Framework:** Spring Boot 2.7.4 (Spring Web, Spring Data JPA, Spring Data REST)
- **Database:** MySQL
- **Build tool:** Maven

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/smit-kalavadiya/Bullseye-Inventory-Project.git
cd Bullseye-Inventory-Project/InventoryManagement
```

### 2. Create the database

Create a MySQL database named `BullseyeInventory`. Schema tables are auto-generated by Hibernate on startup (`spring.jpa.generate-ddl=true`), so no manual migration is needed.

```sql
CREATE DATABASE BullseyeInventory;
```

### 3. Configure the database connection

Update `src/main/resources/application.properties` with your MySQL credentials:

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/BullseyeInventory?allowPublicKeyRetrieval=true&useSSL=false
spring.datasource.username=your_mysql_username
spring.datasource.password=your_mysql_password
spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.MySQL5Dialect
spring.jpa.generate-ddl=true
```

> ⚠️ Don't commit real credentials — use environment variables or a local, git-ignored properties file for anything beyond local development.

### 4. Run the application

Using the Maven wrapper:

```bash
./mvnw spring-boot:run
```

Or with a local Maven install:

```bash
mvn spring-boot:run
```

The API will start on `http://localhost:8080` by default.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/products` | Get all products |
| `POST` | `/products` | Get a product by ID |
| `POST` | `/addproduct` | Add a new product |
| `POST` | `/updateproduct` | Update an existing product |
| `POST` | `/deleteproduct` | Delete a product by ID |
| `GET` | `/Orders` | Get all orders |
| `POST` | `/sendOrder` | Create a new order |
| `POST` | `/updateorder` | Update an order's status |
| `POST` | `/OrderItems` | Add items to an order |
| `POST` | `/getItems` | Get order items by order ID |
| `GET` \| `POST` | `/Employee` | Get all employees |
| `POST` | `/GetEmployee` | Get an employee by email |
| `GET` \| `POST` | `/Supplier` | Get all suppliers |
| `POST` | `/GetSupplier` | Get a supplier by name |
| `POST` | `/Report` | Submit a report |
| `GET` | `/getReportBySubmitted/{name}` | Get reports by recipient |

## Frontend

This backend is built to pair with an Angular frontend running on `http://localhost:4200`. Every controller enables CORS for that origin.
